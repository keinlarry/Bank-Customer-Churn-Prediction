# Data

Le dataset utilisé est disponible publiquement sur Kaggle :

🔗 [Bank Customer Churn Dataset](https://www.kaggle.com/datasets/gauravtopre/bank-customer-churn-dataset)

## Description
- 10 000 clients bancaires (France, Allemagne, Espagne)
- 12 variables : score de crédit, âge, ancienneté, solde, produits, etc.
- Variable cible : `Churn` (1 = churner, 0 = client fidèle)
- Déséquilibre de classes : 20,4% churners / 79,6% fidèles
